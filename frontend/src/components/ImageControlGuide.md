# 图片控制功能使用指南

## 🎯 功能概述

图片控制功能允许您在编辑器中直接调整图片的尺寸和位置，无需手动编写复杂的Markdown语法。

## 🚀 如何使用

### 1. 打开图片控制面板

有两种方式可以打开图片控制面板：

- **方法一**：点击工具栏中的图片按钮 📷
- **方法二**：使用快捷键 `Ctrl+Shift+I`

### 2. 选择图片

- 将光标放在包含图片的行上
- 或者将光标放在图片附近（200字符内）
- 系统会自动识别最近的图片

### 3. 调整图片设置

#### 预设尺寸
- **小图**：页面宽度的40%
- **中图**：页面宽度的70%
- **大图**：页面宽度的90%
- **原始**：保持原始尺寸（不超过页面宽度）

#### 自定义尺寸
- **宽度**：指定图片宽度（像素）
- **高度**：指定图片高度（像素）
- **保持宽高比**：勾选后，只需设置一个维度，另一个会自动计算

#### 对齐方式
- **左对齐** ⬅️：图片与文本左边界完全对齐，无内边距
- **居中** ⬆️：图片在页面中央显示（默认）
- **右对齐** ➡️：图片与文本右边界完全对齐，无内边距

### 4. 应用设置

点击"应用"按钮，系统会自动更新Markdown代码。

## 📝 生成的Markdown语法

### 预设尺寸示例
```markdown
![图片描述](image.png?size=small)
![图片描述](image.png?size=medium)
![图片描述](image.png?size=large)
![图片描述](image.png?size=original)
```

### 自定义尺寸示例
```markdown
![图片描述](image.png?width=200)
![图片描述](image.png?height=150)
![图片描述](image.png?width=300&height=200)
```

### 对齐方式示例
```markdown
![图片描述](image.png?size=medium&align=left)
![图片描述](image.png?size=medium&align=center)
![图片描述](image.png?size=medium&align=right)
```

### 组合使用示例
```markdown
![图片描述](image.png?width=250&align=right)
![图片描述](image.png?size=large&align=left)
```

## 🔄 智能并排显示

系统会自动检测连续的图片并尝试将它们并排显示，以提高页面利用率。

### 自动并排条件

1. **连续图片**：图片之间没有其他内容（允许空行）
2. **宽度适合**：图片总宽度不超过页面可用宽度
3. **数量限制**：每行最多显示3张图片

### 并排显示示例

```markdown
# 两张小图片会并排显示
![图片1](image1.png?size=small)
![图片2](image2.png?size=small)

# 三张小图片会并排显示
![图片A](imageA.png?size=small)
![图片B](imageB.png?size=small)
![图片C](imageC.png?size=small)

# 大图片会分行显示
![大图1](big1.png?size=large)
![大图2](big2.png?size=large)
```

### 并排显示规则

- **小图片**（size=small）：通常可以2-3张并排
- **中等图片**（size=medium）：通常可以2张并排
- **大图片**（size=large）：通常单独显示
- **自定义尺寸**：根据实际宽度计算是否能并排

## 📝 答案和解析标签优化

系统已优化答案和解析标签的显示方式，让标签与后续文本在同一行开始显示。

### 行内显示效果

```markdown
/答案：这是答案内容，与答案标签在同一行开始。

解析：这是解析内容，与解析标签在同一行开始。/
```

### 显示特点

- **紧凑布局**：标签图片与文本无缝连接
- **智能对齐**：标签图片与文本第一行对齐，提供更好的视觉体验
- **统一左对齐**：答案框内所有段落都与第一行左对齐，形成整齐的垂直线
- **无首行缩进**：答案和解析文本不使用首行缩进，保持左对齐
- **自动换行**：长文本会自动换行，保持格式
- **格式保持**：支持粗体、斜体等文本格式
- **多段落支持**：答案框内的多段落正确显示
- **图片功能**：答案框内的图片支持并排显示和对齐功能

### 答案框图片功能

答案框内的图片同样支持智能并排显示和对齐功能：

```markdown
/答案：这是答案内容。

![左对齐图片](image.png?size=small&align=left)
![并排图片1](image1.png?size=small)
![并排图片2](image2.png?size=small)

解析：这是解析内容。

![右对齐图片](image.png?size=medium&align=right)/
```

## 💡 使用技巧

1. **快速调整**：使用预设尺寸可以快速统一文档中图片的大小
2. **精确控制**：需要精确尺寸时使用自定义宽高
3. **保持比例**：勾选"保持宽高比"避免图片变形
4. **精确对齐**：左/右对齐确保图片与文本边界完全对齐，无内边距
5. **智能并排**：连续的小图片会自动并排显示，提高页面利用率
6. **布局设计**：使用对齐功能创建更丰富的页面布局
7. **视觉一致性**：统一的对齐方式让文档看起来更专业

## 🔧 快捷键

- `Ctrl+Shift+I`：打开图片控制面板
- `Ctrl+B`：加粗文本
- `Ctrl+I`：斜体文本
- `Tab`：插入缩进

## 📋 注意事项

1. 图片文件需要存在于指定路径
2. 网络图片需要先缓存到本地
3. 图片尺寸不会超过页面最大宽度
4. **精确对齐**：左/右对齐确保图片边界与文本边界完全重合
5. **对齐一致性**：图片说明（alt文本）会根据对齐方式调整位置
6. **PDF渲染**：所有对齐效果在PDF中都会正确显示
7. **无内边距**：对齐图片使用零内边距确保精确定位
8. **智能并排**：连续图片会自动检测并排显示的可能性
9. **空行分隔**：图片间有空行时会分别处理，不会并排
10. **并排限制**：每行最多3张图片，超出会自动换行
11. **答案标签优化**：答案和解析标签与后续文本在同一行开始
12. **智能对齐**：标签图片与文本第一行对齐，长文本显示更直观
13. **段落对齐**：答案框内所有段落都与第一行左对齐，形成整齐的垂直线
14. **无首行缩进**：答案框内文本不使用首行缩进，与标签图片完美对齐
15. **答案框图片**：答案框内的图片支持并排显示和对齐功能
16. **紧凑布局**：标签图片与文本无缝连接，提高空间利用率
